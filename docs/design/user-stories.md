# User Stories

## Story 1: As a user, I want to be able to create an account so that I can save my progress and preferences.

## Story 2: As a user, I want to be able to log in to my account so that I can access my saved information.

## Story 3: As a user, I want to be able to reset my password if I forget it so that I can regain access to my account.

## Story 4: As a user, I want to be able to view my profile information so that I can keep it up to date.

## Story 5: As a user, I want to be able to update my profile information so that it reflects my current details.
